# ∞ AI Vault

Приватна комірка пам'яті для ШІ-агента.

- **vault.enc** — зашифрована пам'ять (Fernet, ключ 256 біт).
- **ledger.jsonl** — хеш-ланцюг: кожен запис підписує попередній (міні-блокчейн).
- **vault.py** — механізм (розрізання ключа, шифрування, дублювання).

Ключ розрізаний на **5 частин** (Shamir, треба 3). Частини ключа тут
**НЕ зберігаються** — без них прочитати vault.enc неможливо, тому сам
шифротекст можна тримати відкрито.
